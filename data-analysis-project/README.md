1. 프로젝트 주제: 골프 샷 데이터 기반 비거리 관련 요인 및 클럽별 특성 분석-> 골프 샷 데이터로 비거리 및 정확도 분석

2. 해결하고 싶은 문제
골프 샷의 결과는 단순히 클럽 종류만으로 결정되지 않고 볼 스피드, 발사각, 스핀 등 여러 측정값과 관계가 있다. 따라서 어떤 측정값이 비거리와 샷 결과에 관계가 있는지 데이터로 확인한다

3. 핵심 분석 질문
    1. 클럽별 볼 스피드, 발사각, 스핀량, 캐리 거리에는 어떤 차이가 있는가?
    2. 볼 스피드, 발사각, 스핀량은 캐리 거리와 어떤 관계를 보이는가?
    3. 캐리 거리와 상대적으로 강한 관계를 보이는 측정 변수는 무엇인가?
    4. (확장 질문) 비슷한 볼 스피드 조건에서 발사각과 스핀량에 따라 캐리 거리는 어떻게 달라지는가?

5. 예상 분석 방법
데이터 전처리,기술통계,그룹별 비교,시각화,상관 분석,필요 시 회귀 분석
클럽별 볼 스피드, 스핀량, 캐리 거리의 차이를 기술통계와 시각화로 비교하고, 주요 측정 변수와 캐리 거리의 관계를 상관 분석을 통해 확인할 예정이다. 이후 필요할 경우 캐리 거리를 목표변수로 하는 간단한 회귀 분석을 추가로 수행한다.

- 분석 목적과 핵심 분석 질문 구체화
- 데이터 컬럼의 의미와 분석 가능 변수 검토
- 데이터 구조 및 품질 확인 방법 검토
- 결측치, 중복, 이상값 및 자료형 처리를 위한 전처리 코드 작성 보조
- Pandas를 활용한 EDA 코드 작성 및 개선
- Matplotlib 등을 활용한 시각화 코드 작성 보조
- 분석 질문에 적합한 통계 분석 및 회귀 방법 검토
- Python 코드 실행 중 발생하는 오류의 원인 분석 및 해결

생성형 AI가 작성한 코드와 분석 결과를 그대로 사용하지 않고, 실제 데이터와 코드 실행 결과를 기준으로 직접 검증한다. 특히 AI가 제안한 변수의 의미, 통계적 해석, 모델 성능에 대한 설명이 실제 데이터와 일치하는지 확인한 뒤 최종 결과에 반영한다.

7. 향후 프로젝트 계획
1단계. 데이터 확인 및 정리: 기취득한 약 500개의 골프 샷 데이터를 확보하고, 데이터의 컬럼 구성과 각 측정값의 의미를 확인한다.
2단계. 데이터 구조 및 품질 확인: 데이터 크기, 자료형, 결측치, 중복값, 이상값을 확인하고 분석에 사용할 변수와 제외할 변수를 결정한다.
3단계. 데이터 전처리: 분석에 필요한 수치형 및 범주형 변수를 정리하고, 잘못된 자료형과 비정상적인 측정값을 처리한다. 동일한 물리량에 대해 여러 측정 방식의 컬럼이 존재하는 경우 각 컬럼의 의미를 확인하고 분석 기준을 결정한다.
4단계. 탐색적 데이터 분석(EDA): 주요 변수의 분포를 확인하고 클럽별 Ball Speed, 발사각, Spin, Carry Distance 등의 차이를 기술통계와 시각화를 통해 비교한다.
5단계. 본 분석 및 모델링: Ball Speed, 발사각, Spin 관련 변수와 Carry Distance 사이의 관계를 상관 분석과 회귀 분석을 통해 확인한다. 전체 데이터와 클럽별 데이터를 구분하여 분석하고 필요할 경우 간단한 머신러닝 회귀 모델을 적용한다.
6단계. 결과 검증: 분석 결과가 특정 클럽이나 일부 샷에 의해 발생한 결과인지 확인하고, 회귀 모델을 적용한 경우 평가 데이터를 이용하여 예측 성능을 검증한다.
7단계. 시각화 및 인사이트 도출: 분석 결과를 그래프와 표로 정리하고, 데이터에서 직접 확인할 수 있는 결과와 그 결과에 대한 해석을 구분하여 작성한다.
8단계. 최종 결과물 작성: 전체 분석 과정을 Jupyter Notebook과 분석 보고서로 정리하고 GitHub Repository에서 단계별 산출물과 변경 내용을 관리한다. 가능할 경우 최종 단계에서 Streamlit을 이용하여 클럽별 샷 특성과 주요 분석 결과를 확인할 수 있는 간단한 대시보드로 확장한다.
