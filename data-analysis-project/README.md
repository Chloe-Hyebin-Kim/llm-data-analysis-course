2. 해결하고 싶은 문제
다음 내용을 간단히 설명합니다.

어떤 문제 또는 현상에 관심이 있는가?

왜 이 문제를 분석하려고 하는가?

분석 결과를 누가 또는 어디에 활용할 수 있는가?

3. 핵심 분석 질문
프로젝트에서 데이터로 확인하고 싶은 질문을 2~3개 이상 작성합니다.

예:

1. 지역별 아파트 가격에는 어떤 차이가 있는가?
2. 면적·연식·교통 접근성과 가격은 어떤 관계가 있는가?
3. 가격에 상대적으로 큰 영향을 주는 변수는 무엇인가?
단순히

아파트 데이터를 분석한다.
라고 작성하기보다 실제 데이터로 답할 수 있는 질문 형태로 작성하는 것을 권장합니다.

4. 데이터 확보 계획
사용할 데이터의 출처와 확보 방법을 작성합니다.

데이터 확보 방법은 자유롭게 선택할 수 있습니다.

예:

Kaggle

웹 크롤링

기업·기관 공개 자료
설문조사
직접 관찰 또는 측정
실험 데이터
DB / 시스템 로그 / CSV·Excel Export
기타 직접 확보 가능한 데이터
다음 내용을 포함해 주세요.

데이터 출처

데이터 URL 또는 접근 방법

데이터 수집 방법

실제 확보 가능 여부

특히 다음 질문에 답할 수 있어야 합니다.

데이터는 어디에서 오는가?
어떻게 수집할 것인가?
얼마나 확보할 수 있는가?

6. 생성형 AI 활용 계획
ChatGPT, Claude, Gemini, Copilot 등의 생성형 AI를 적극 활용할 수 있습니다.

예:

분석 질문 구체화

시각화

보고서 작성
다만 AI가 생성한 코드와 해석은 반드시 실제 데이터와 실행 결과를 기준으로 직접 검증해야 합니다.

7. 향후 프로젝트 계획
현재 예상하는 진행 방향을 간단히 정리합니다.

데이터 확보
→ 데이터 구조·품질 확인
→ 전처리
→ 탐색적 데이터 분석(EDA)
→ 본 분석 또는 모델링
→ 결과 검증
→ 시각화 및 인사이트
→ 최종 결과물 작성
최종 단계에서는 가능하면 Notebook 및 분석 보고서와 함께 Streamlit 등을 활용한 결과 전달도 진행할 예정입니다.
