
# 1. 프로젝트 제목

골프 샷 데이터로 비거리 및 정확도 분석

---

# 2. 프로젝트 배경 및 목적

골프 샷의 결과는 단순히 클럽의 종류만으로 결정되지 않고 볼 스피드, 발사각, 클럽 스피드, 스핀량, 스핀축, 볼 방향 등 다양한 측정값과 관계가 있다.

본 프로젝트에서는 상용 센서를 이용하여 직접 취득한 골프 샷 데이터를 분석하여, 클럽별 샷 특성을 비교하고 어떤 측정값이 비거리 및 샷 방향과 관계가 있는지 확인하고자 한다.

특히 볼 스피드, 발사각, 스핀 관련 변수와 캐리 거리의 관계를 분석하고, 클럽 종류에 따라 이러한 측정값이 어떻게 달라지는지 확인하는 것을 주요 목적으로 한다.

분석 결과는 골프 샷 특성을 정량적으로 이해하고, 향후 골프 시뮬레이터의 측정 결과 분석이나 샷 평가 기준을 검토하는 데 활용할 수 있다.

---

# 3. 핵심 분석 질문

1. 클럽별 볼 스피드, 발사각, 스핀량, 캐리 거리에는 어떤 차이가 있는가?
2. 볼 스피드, 발사각, 스핀량은 캐리 거리와 어떤 관계를 보이는가?
3. 캐리 거리와 상대적으로 강한 관계를 보이는 측정 변수는 무엇인가?
4. 확장 질문: 비슷한 볼 스피드 조건에서 발사각과 스핀량에 따라 캐리 거리는 어떻게 달라지는가?

추가적으로 데이터 품질과 분석 가능 여부에 따라 Ball Direction, Side Spin, Spin Axis 등을 활용하여 클럽별 샷 방향 및 정확도 특성도 분석할 예정이다.

# 4. 데이터 확보 계획

- 데이터 출처: 상용 센서를 이용하여 직접 획득한 골프 샷 데이터
- 데이터 URL 또는 접근 방법: CSV 파일 형태로 확보
- 예상 데이터 규모: 약 500개의 샷 데이터
- 데이터 수집 방법: 직접 관찰 및 측정을 통한 실험 데이터
- 실제 확보 가능 여부: 기취득 완료

본 프로젝트에서는 이미 확보한 데이터를 사용하므로 추가적인 웹 크롤링이나 외부 API 호출 없이 분석을 진행할 수 있다.

데이터에는 볼 및 클럽의 움직임, 스핀 정보, 처리 시간, 측정 환경, 클럽 종류 등 다양한 정보가 포함되어 있으며, 분석 목적에 따라 필요한 컬럼을 선택하여 사용할 예정이다.

# 5. 예상 데이터 구조

예상 데이터는 약 500개의 골프 샷을 행 단위로 구성하며, 각 샷에 대한 측정값이 컬럼으로 저장되어 있다.

주요 변수는 다음과 같다.

| 구분 | 주요 변수 | 설명 |
|---|---|---|
| 기본 정보 | Date, ShotDB Name | 샷 측정 일시 및 데이터 식별 정보 |
| 볼 특성 | Ball Speed | 볼 속도 |
| 볼 방향 | Ball Incidence, Ball Direction | 볼의 발사 및 진행 방향 관련 정보 |
| 클럽 특성 | Club Speed, Attack Angle, Club Path, Face Angle, Dynamic Loft | 클럽의 속도 및 임팩트 특성 |
| 스핀 특성 | Back Spin, Side Spin, Total Spin, Spin Axis | 볼 회전 특성 |
| Spin 측정값 | Back Spin(Spin), Side Spin(Spin), Total Spin(Spin), Spin Axis(Spin) | Spin 방식으로 측정한 회전 정보 |
| AI 측정값 | Back Spin(AI), Side Spin(AI), Total Spin(AI), Spin Axis(AI) | AI 방식으로 계산한 회전 정보 |
| 품질 및 처리 정보 | Confidence(Spin), Proc Time, Light Level, Frame Drop | 측정 신뢰도 및 처리 환경 정보 |
| 범주형 정보 | Club Type, Mat Type | 클럽 종류 및 매트 종류 |

분석 전에 각 컬럼의 자료형과 단위, 측정 방법을 확인하고 실제 분석에 필요한 컬럼을 선정할 예정이다.

또한 동일한 물리량에 대해 일반 측정값, Spin 기반 측정값, AI 기반 측정값 (추후 논문 작성시)이 함께 존재하므로 각 컬럼의 의미를 확인한 뒤 분석 목적에 맞는 값을 사용할 예정이다.

# 6. 예상 분석 방법

본 프로젝트에서는 분석 질문에 필요한 방법을 중심으로 다음과 같은 분석을 수행할 예정이다.

- 데이터 전처리
- 기술통계
- 그룹별 비교
- 시각화
- 상관 분석
- 필요 시 회귀 분석

먼저 결측치, 중복값, 이상값, 자료형 등을 확인하여 데이터를 정리한다.

이후 클럽별 볼 스피드, 발사각, 스핀량, 캐리 거리 등의 차이를 기술통계와 시각화를 통해 비교한다.

산점도와 상관 분석을 이용하여 볼 스피드, 발사각, 스핀 관련 변수와 캐리 거리 사이의 관계를 확인하고, 캐리 거리와 상대적으로 강한 관계를 보이는 변수를 탐색한다.

필요할 경우 캐리 거리를 목표변수로 설정하고 주요 측정값을 설명변수로 사용하는 간단한 회귀 분석을 수행하여 변수와 비거리의 관계를 추가로 확인할 예정이다.

# 8. 향후 진행 계획

프로젝트는 다음 순서로 진행할 예정이다.
1단계. 데이터 확인 및 정리: 기취득한 약 500개의 골프 샷 데이터를 확보하고, 데이터의 컬럼 구성과 각 측정값의 의미를 확인한다.
2단계. 데이터 구조 및 품질 확인: 데이터 크기, 자료형, 결측치, 중복값, 이상값을 확인하고 분석에 사용할 변수와 제외할 변수를 결정한다.
3단계. 데이터 전처리: 분석에 필요한 수치형 및 범주형 변수를 정리하고, 잘못된 자료형과 비정상적인 측정값을 처리한다. 동일한 물리량에 대해 여러 측정 방식의 컬럼이 존재하는 경우 각 컬럼의 의미를 확인하고 분석 기준을 결정한다.
4단계. 탐색적 데이터 분석(EDA): 주요 변수의 분포를 확인하고 클럽별 Ball Speed, 발사각, Spin, Carry Distance 등의 차이를 기술통계와 시각화를 통해 비교한다.
5단계. 본 분석 및 모델링: Ball Speed, 발사각, Spin 관련 변수와 Carry Distance 사이의 관계를 상관 분석과 회귀 분석을 통해 확인한다. 전체 데이터와 클럽별 데이터를 구분하여 분석하고 필요할 경우 간단한 머신러닝 회귀 모델을 적용한다.
6단계. 결과 검증: 분석 결과가 특정 클럽이나 일부 샷에 의해 발생한 결과인지 확인하고, 회귀 모델을 적용한 경우 평가 데이터를 이용하여 예측 성능을 검증한다.
7단계. 시각화 및 인사이트 도출: 분석 결과를 그래프와 표로 정리하고, 데이터에서 직접 확인할 수 있는 결과와 그 결과에 대한 해석을 구분하여 작성한다.
8단계. 최종 결과물 작성: 전체 분석 과정을 Jupyter Notebook과 분석 보고서로 정리하고 GitHub Repository에서 단계별 산출물과 변경 내용을 관리한다. 가능할 경우 최종 단계에서 Streamlit을 이용하여 클럽별 샷 특성과 주요 분석 결과를 확인할 수 있는 간단한 대시보드로 확장한다.

전체 진행 과정은 다음과 같다.

데이터 확보 -> 데이터 구조 및 품질 확인 -> 전처리 -> 탐색적 데이터 분석(EDA) -> 본 분석 및 모델링 -> 결과 검증 -> 시각화 및 인사이트 도출 -> 최종 결과물 작성
